CLI Commands Cheat Sheet
telesend bot list List registered bots
telesend bot add Register bot by prompt
telesend bot default <bot> Set active default bot

telesend bot remove <bot> Remove bot registration
telesend alias add <name> <chat-id> Add recipient shortcut
telesend alias list [group|private] List aliases with filter
